# Мова гіпертекстової розмітки HTML — урок 2

Інтерактивний навчальний сайт для уроку інформатики в 11 класі. Тема: **абзаци, заголовки, перенесення рядка (`<br>`), горизонтальна лінія (`<hr>`) та вирівнювання абзаців і заголовків**.

## Мета уроку

Навчитися створювати й форматувати заголовки та абзаци в HTML-документі, використовувати теги `<br>` і `<hr>`, налаштовувати вирівнювання тексту, знаходити та виправляти помилки в коді.

## Що містить сайт

1. **Теорія HTML** — основні поняття, структура документа, теги, атрибути та приклади коду.
2. **Пам’ятка** — таблиця тегів і прикладів використання для роботи із заголовками та абзацами.
3. **Інтерактивне завдання** — розміщення фрагментів HTML-коду в правильному порядку з автоматичною перевіркою.
4. **«HTML-детектив»** — дві тематичні картки («Нововолинськ — моє місто» та «Робототехніка»), по 12 помилок у кожній, із редактором, перевіркою та ключами відповідей.
5. **Практична робота «Тарас Шевченко»** — три маршрути складності, стартовий шаблон, редактор коду, попередній перегляд та збереження результату як HTML-файлу.
6. **Критерії та самооцінювання** — шість критеріїв, загалом 12 балів, підсумок і рефлексія.

## Як запустити

1. Завантажте архів проєкту й розпакуйте його.
2. Відкрийте файл `index.html` у сучасному браузері.
3. Для роботи з навчальними вправами додаткове програмне забезпечення не потрібне.

## Як опублікувати на GitHub Pages

1. Увійдіть у GitHub і створіть новий репозиторій (наприклад, `html-lesson-2`).
2. Завантажте в корінь репозиторію файли `index.html` та `README.md`.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** оберіть **Deploy from a branch**.
5. Виберіть гілку `main`, папку **/(root)** і натисніть **Save**.
6. Дочекайтеся публікації. Посилання на сайт з’явиться в розділі **Pages**; зазвичай воно має вигляд `https://ІМʼЯ-КОРИСТУВАЧА.github.io/html-lesson-2/`.

> Важливо: для GitHub Pages головна сторінка повинна називатися саме `index.html`.
